# Coaching Reports Preview

Temporary native React preview of the separate Coaching Report Dashboard prototype.

This folder should be removed when preview testing ends. It is intentionally isolated from NBA Dashboard data, Supabase, Looker, and live NBA feeds. The page uses only embedded sample data from the prototype and local preview assets.

Remove with:
- `src/features/coachingReportsPreview/`
- the `/coaching-reports-preview` route in `src/App.jsx`
- the `Coaching Reports Preview` dropdown link in `src/components/Header.jsx`
- `docs/coaching-reports-preview-removal.md`
